# 手册

手册把多张知识卡片综合成面向未来任务或复用情境的行动指引。

默认 Career Playbook：

- [[申请材料]] — JD analysis、CV、cover letter、申请邮件与作品集选择 / tailoring。
- [[Networking 与内推]] — outreach、LinkedIn / email messaging、coffee chat、follow-up 与 referral。
- [[行为面试]] — STAR、challenge / failure / conflict、leadership、prioritization、trade-offs 与 collaboration。
- [[专业面试]] — portfolio / project storytelling、professional judgment、design critique、case / design challenge 与 role-specific knowledge。
- [[HR 面试]] — recruiter screen、自我介绍、motivation、Why role / company、薪资、签证、availability、offer / negotiation 与 HR handoff。
- [[其他]] — 不明确属于以上情境、但仍有求职复用价值的知识。

这些手册保持轻量，只在用户明确要求 synthesis 时根据相关 Knowledge Cards 更新。用户可以重命名、合并、删除或新增手册。
